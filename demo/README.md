# Demo assets

Place a recording of `selfheal` running end-to-end here as `demo.gif`
(referenced by the project README). A good demo shows:

1. Running `selfheal "<task>" --yes` in a terminal.
2. Attempt 1 failing with a visible red traceback.
3. Claude generating a fix.
4. Attempt 2 succeeding, clearly marked.

Terminal recording tools like [asciinema](https://asciinema.org/) (converted
to GIF with [agg](https://github.com/asciinema/agg)) or
[vhs](https://github.com/charmbracelet/vhs) work well for this.
